# Wetin Be Dis — Website

The interactive marketing, support, and privacy site for **Wetin Be Dis**, the Nigerian party guessing game.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Next.js exports the static site to `out/`. Netlify deploys that directory using the settings in `netlify.toml`.

## Routes

- `/` — interactive brand and gameplay experience
- `/support/` — support and contact information
- `/privacy/` — privacy policy
